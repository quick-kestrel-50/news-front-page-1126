**The Daily Globe** — the world news of Thursday 26 November 2026, summed up in a single image drawn as a newspaper front page.

The lead story is the Strait of Hormuz tanker crisis: Iran says two oil tankers struck naval mines and caught fire — the latest in a string of such claims, none independently verified. Tehran says shipping will not return to normal until its demands are met; earlier in November it offered to reopen the strait within 48 hours if Washington accepts its conditions. Around it: Trump's proposed new tariffs on 14 trading partners, Pakistan's first astronaut reaching the Tiangong station aboard Shenzhou-24, the end of the supermarket hostage siege in Cartagena, the Houthi strike on Saudi Arabia's Ras Tanura refinery, and Israel's killing of Hamas security chief Mohammad Abuelouf in northern Gaza — plus an "Also Today" strip with the COP31 collapse, the Dow back above 50,000, Miss Universe 2026, the Australia–Solomon Islands treaty, and North Korea's expulsion of the Swiss envoy. All stories were compiled from Reuters, AP and AFP reporting of 25–26 November 2026, and every picture on the page was drawn for this page.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `entry.png` (1024×1024) to the output directory. `generate_image.py` is the program that drew the front page; the PNG it produced is committed as `entry.png`, and `main.ts` publishes exactly those bytes.
